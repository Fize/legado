# Legado 3.2 UI 优化方案

状态：设计已定稿，待实施。

3.2 的重点是缩短「续读、找书、整理书架」的操作路径。继续使用 Android 原生 Compose 和 Material 3，以手机书架为首要验收页面。

**范围边界：阅读器不参与改版。** 正文渲染、排版、翻页、工具栏布局及展开方式保持现状。续读入口和退出后恢复书架位置属于书架导航改动。

## 视觉与主题

默认采用固定的 Google 系蓝灰亮暗配色，不以壁纸取色作为默认行为。书封保留原色；蓝色用于主操作和选中状态，普通信息使用中性色。应用主题不覆盖阅读器的纸色设置。

## 实施顺序与交互

| 顺序 | 页面 | 交互与布局 |
| --- | --- | --- |
| 1 · P0 | 主题基础与书架首页 | 有阅读进度时显示紧凑续读栏；点击「继续」直达上次位置，返回后恢复分组和滚动位置。散书和分组继续按最近阅读时间混排，统一封面区域与标题基线，不恢复「全部」或「未分组」卡片。保留搜索和添加入口，暂不添加独立筛选入口。 |
| 2 · P0 | 分组与批量整理 | 长按书籍进入多选，顶部显示已选数量和退出入口，底部突出「加入分组」。无选中项时禁用批量操作。「移出分组」与「从书架移除」分开，后者执行前确认。 |
| 3 · P1 | 搜索与书籍详情 | 书架搜索只查已入架的书，发现页用于找新书。返回时保留搜索词和结果位置。详情主操作按状态显示「加入书架」「开始阅读」或「继续阅读」。 |
| 4 · P1 | 发现、我的与设置 | 统一亮暗配色、页面层级和反馈样式。书源、规则、备份继续作为管理工具；发现加载失败可就地重试。 |
| 5 · 手机验收后 | 平板与横屏 | 延续原生自适应导航，再评估书架＋详情双栏。验证旋转与分屏后的页面状态保留。 |

## 验收

- **续读闭环**：从书架点「继续」恢复阅读位置，系统返回后仍在进入前的分组和滚动位置。
- **搜索闭环**：输入关键词，打开一条结果，再返回；搜索词和结果位置保留。
- **整理闭环**：长按进入多选，勾选多本书并加入分组；取消选择不修改书籍，移出分组不等于从书架移除。
- **异常与可访问性**：空书架提供「导入本地」和「找书」；无搜索结果可清除搜索词，无筛选结果可清除筛选；加载失败可重试。三条主路径均在亮暗主题下验证，并检查大字体与 TalkBack 下的关键操作。
- **阅读器回归**：同一本书升级前后对照，正文和控件布局、翻页及工具栏展开行为保持一致。
